Este repositorio contiene el código fuente de mi portafolio web, desarrollado con **HTML5**, **CSS3** y **JavaScript**. El objetivo del proyecto es presentar mi perfil profesional, habilidades, proyectos y formas de contacto en un sitio web moderno, responsivo e intuitivo.

## 🚀 Demo

Puedes visitar el portafolio en el siguiente enlace:

🔗 **https://TU-USUARIO.github.io/TU-REPOSITORIO/**

> Reemplaza `TU-USUARIO` y `TU-REPOSITORIO` por los datos correspondientes de tu repositorio en GitHub.

## ⚙️ Instalación

1. Clona este repositorio:

```bash
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git
````

2. Accede al directorio:

```bash
cd TU-REPOSITORIO
```

3. Abre el archivo `index.html` en tu navegador.

No es necesario instalar dependencias ni utilizar un servidor.
